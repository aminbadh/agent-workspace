# Add-ons

Optional parts of the workspace, kept out of the way until they are wanted. Each folder here is one add-on that is not installed yet. Its README says what it gives, where its files go and the row it adds to [AGENTS.md](../../AGENTS.md)'s skills table.

The onboard skill moves an add-on in when the user picks it, at onboarding or later: say "add the applications add-on" or similar. Once moved in, its folder here is removed; this folder stays, so another can be added later.

Files inside an add-on are written for where they land once moved in, so their links only resolve there. The linter skips this folder for that reason.
