# Tasks

The task home for this workspace: every task and every date to act on lives here, and nowhere else in the repo. Reasoning lives in the domains; a task can say which one. The rules for writing tasks are in [CONVENTIONS.md](.agents/CONVENTIONS.md#the-task-home).

One line per task: `- [ ] Verb-first action (domain) due YYYY-MM-DD`. The domain and the date are optional. Tick a task when it is done; the weekly review clears ticked ones.
