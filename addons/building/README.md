# Add-on: Building

For anyone who writes code with AI agents and wants the workspace to plan it.

**What it gives:** BUILDING.md, the overseer and builders workflow. One session in this workspace thinks, plans and keeps the docs true; short-lived sessions inside each code repo build, one written brief each. It also covers paths across machines, so the workspace can be reached from code repos and cloned on more than one computer.

**Where its files go:**

| From | To |
|---|---|
| `BUILDING.md` | `BUILDING.md` at the workspace root |

**Row it adds to AGENTS.md's skills table:**

```markdown
| [Building](BUILDING.md) | Writing a brief, launching a builder or reviewing one. Read it before planning code work |
```

It has no skill of its own: the workflow is a file the agent reads before any code work, linked from the table.
